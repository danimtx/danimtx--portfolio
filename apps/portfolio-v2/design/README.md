# Espacio de Diseño & Planificación (Portfolio V2)

Este directorio centraliza las referencias visuales, imágenes generadas, análisis de diseño y planes del proyecto antes y durante el desarrollo de **Portfolio V2**.

## 📁 Estructura de carpetas

- 📸 **`references/`**: Coloca aquí tus imágenes de referencia, capturas de pantalla de sitios web inspiracionales, paletas o wireframes que quieras tomar como base.
- 🎨 **`generated/`**: Imágenes, logos, mockups y recursos visuales generados por IA o herramientas de diseño para este portafolio.
- 🧠 **`skills-output/`**: Análisis de dirección de arte, tokens de diseño, tipografía, motion design y auditorías de interfaces (generadas con nuestras skills de diseño).
- 📋 **`plans/`**: Hoja de ruta, especificaciones técnicas, arquitectura de componentes y planes paso a paso del proyecto.
